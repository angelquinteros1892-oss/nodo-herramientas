📊 Actualizar Precios (desde Excel)

Para actualizar los precios, debés regenerar el archivo data/productos.json a partir del Excel actualizado.

⚠️ Siempre hacer una copia del JSON anterior antes de regenerar.
  1. Editá el Excel Nodo_Herramientas_Lusqtoff_Listas_Mayorista_Minorista.xlsx con los nuevos precios en la hoja Base_Costos, columnas F (precio compra).
  2. Instalá Python 3 en tu computadora si no lo tenés: python.org
  3. Instalá la librería necesaria: abrí una terminal y escribí pip install openpyxl
  4. Ejecutá el script: python exportar.py (el archivo Python que está en la raíz del proyecto)
  5. El JSON se regenera automáticamente. Subí el nuevo data/productos.json al hosting.

💬 Cambiar número de WhatsApp

Editá el archivo js/app.js y cambiá la línea al principio:

const CONFIG = {
  wsp: '5493517000000', // ← Poner el número real sin + ni espacios
  wsp_display: '+54 9 351 700-0000',
  ...
};

Formato correcto para Argentina: 5493511234567 (54 + 9 + código área sin 0 + número sin 15)

🐙 Publicar en GitHub Pages

  1. Creá una cuenta en github.com si no tenés.
  2. Creá un repositorio nuevo llamado nodo-herramientas (público).
  3. Subí todos los archivos del proyecto al repositorio.
  4. Andá a Settings → Pages → Source, elegí main branch y guardá.
  5. Tu sitio estará en https://tuusuario.github.io/nodo-herramientas
⚠️ GitHub Pages requiere que el sitio use rutas relativas (ya configuradas).

🌐 Publicar en Hostinger

  1. Contratá un hosting en Hostinger Argentina.
  2. Accedé al panel hPanel → Administrador de Archivos.
  3. Entrá a la carpeta public_html.
  4. Subí todos los archivos y carpetas del proyecto directamente ahí.
  5. El sitio estará activo en tu dominio contratado.

🖼️ Agregar imágenes de productos

Las imágenes se asocian por código de producto. Para agregar imágenes:

  1. Guardá la imagen con el nombre del código: ejemplo AB-550.jpg
  2. Subila a la carpeta assets/imagenes/
  3. En el archivo data/productos.json, buscá el producto por código y completá el campo "imagen":
{ 
  "codigo": "AB-550",
  "imagen": "assets/imagenes/AB-550.jpg",
  ...
}

Formatos soportados: .jpg, .jpeg, .png, .webp. Tamaño recomendado: 400x400px.
